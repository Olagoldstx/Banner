# SecureTheCloud Brand Assets & Usage Guidelines

Thank you for using the SecureTheCloud brand assets! Please follow these guidelines to ensure our brand is represented consistently and professionally.

## 📁 File Overview

This package contains the following assets:

*   `securethecloud-logo.png` - Primary logo for use on light backgrounds.
*   `securethecloud-logo-transparent.png` - Logo with transparent background for use on colored or image backgrounds.
*   `securethecloud-banner-dark.png` - Header banner for use on dark backgrounds.
*   `securethecloud-banner-light.png` - Header banner for use on light backgrounds.

## 🎨 Logo Usage

### Clear Space
To ensure legibility and impact, always maintain a minimum clear space around the logo. This space should be at least equal to the height of the "S" in "Secure" from the logo.

![Clear Space Diagram](https://via.placeholder.com/400x200/FFFFFF/555555?text=Clear+Space+Example)

### Dos and Don'ts

| Do ✅ | Don't ❌ |
| :--- | :--- |
| Use the transparent logo on non-white backgrounds. | Stretch, skew, or distort the logo. |
| Use the primary logo on white or light backgrounds. | Change the colors of the logo. |
| Maintain the provided clear space. | Add effects like drop shadows, bevels, or glows. |
| Scale the logo proportionally. | Rotate the logo. |
| | Place the logo on a busy or low-contrast background. |

### Minimum Size
To ensure readability, the logo should never be reproduced at a width smaller than **150 pixels** for digital use.

## 🚫 Improper Usage Examples

The following are examples of incorrect logo usage that are **not permitted**:

*   **Distortion:** Do not stretch or change the proportions.
*   **Rotation:** Do not rotate the logo.
*   **Effects:** Do not add external effects like shadows or glows.
*   **Re-coloring:** Do not change the official brand colors.
*   **Re-arrangement:** Do not separate the icon from the wordmark or alter their arrangement.

## 🖼️ Banner Usage

The banners are designed for website headers, conference presentation slides, and social media cover images.

*   Use `securethecloud-banner-light.png` on light-colored pages or slides.
*   Use `securethecloud-banner-dark.png` on dark-colored pages or slides.

Do not modify the banners. If you require a custom banner size or a specific format, please contact the marketing team.
